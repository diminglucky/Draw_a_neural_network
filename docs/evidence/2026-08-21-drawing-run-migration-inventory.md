- **Private** means source bytes, provider context, credentials, filesystem/path details, worker internals, or stored execution detail.

## Migration decisions

1. UGS remains the only structural truth and PVP remains the only visual truth. NetworkIR, FigureAnalysis, and the free-text M2.12 prototype are adapters or fixtures, not another future pipeline.
2. New requests begin at `DrawingIntent`; they cannot route raw input to legacy preview, export, or Visio paths. Candidate or blocking assessments stop before PVP, Snapshot, export, Worker, COM, or page binding.
3. M3.6 is the only planned current-page Visio claim. It needs a selected existing target, an Agent-owned region, owner/device/run/revision-bound sealing, preserved-shape conflict checks, independent readback, and an explicit real-host lifecycle matrix.
4. Rollback disables a new versioned route or binding selection. It never silently reroutes a new request through the free-text interpreter, `OpenOrCreate`, or a VGG-specific bridge.
